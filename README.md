Aventuras Felinas

Pixel Paws

Descripción

Aventuras Felinas es un videojuego 2D estilo pixel art donde controlas a un gato aventurero que explora escenarios coloridos, completa misiones y supera obstáculos. El juego está diseñado para ser accesible, intuitivo y divertido para todo tipo de jugadores.

Objetivo del Proyecto

Desarrollar un videojuego entretenido y visualmente atractivo, con mecánicas simples de exploración, recolección de ítems y superación de niveles.

Características Principales

-Personaje principal jugable (gato).

-Niveles explorables en 2D.

-Enemigos con patrones sencillos.

Interfaz intuitiva.

Tecnologías Utilizadas

-Motor de desarrollo: Godot Engine

-Diseño de arte pixel: Pixilart

Modelo de Negocio

-El proyecto está dirigido a:

-Niños y adolescentes

-Jugadores casuales

-Amantes de los gatos y del pixel art

-Posible distribución en plataformas como:

-Steam

-Google Play Store

-App Store

Alcance

-Videojuego 2D funcional.

-Versión para PC.

-Mecánicas básicas implementadas.

-Diseño bajo metodología Lean Startup (Construir–Medir–Aprender).
